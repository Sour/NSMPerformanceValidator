# Quality Runs are compared by Rep Length, not exact Format

Progress charts group Quality Runs by Rep Length (10:00, 6:00, 3:00) rather than by the full Quality Run Format (e.g. 4 × 6:00). The NSM plan changes rep counts and recoveries as it progresses, and keying on the exact Format would restart each history from zero at every plan change. Pace for a given Rep Length is largely independent of how many Reps are run, so changes in rep count or recovery are annotated on the chart instead of splitting the line.
